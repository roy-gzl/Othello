# Othello

このプログラムは，2021年に大学の授業課題として作成したC言語製のオセロです．
ターミナル上で2人対戦できるように作っており，あとから少しずつ機能を追加しています．

## 概要

8x8の盤面で遊ぶ，コンソール版のオセロです．
盤面には現在のプレイヤーが置ける場所が `+` で表示されます．

盤面の表示は以下の意味です．

- `○`: PLAYER1の石
- `●`: PLAYER2の石
- `+`: 現在のプレイヤーが置ける場所
- `.`: 空きマス

## コンパイル

`Othello.c` があるディレクトリで，次のコマンドを実行します．

```sh
clang -std=c17 Othello.c -o Othello
```

`gcc` を使う場合は次のようにします．

```sh
gcc -std=c17 Othello.c -o Othello
```

## 実行

```sh
./Othello
```

## 遊び方

手番になると，現在のプレイヤーと盤面が表示されます．

```text
○ PLAYER1
```

置きたい場所の座標を，`x`，`y` の順に入力します．

```text
input x:5
input y:3
```

入力できる座標は `1` から `8` です．
置けない場所を入力すると，もう一度入力を求められます．

## 実装済みの機能

- 8方向の置ける場所判定
- 石の反転処理
- 置ける場所の `+` 表示
- 置ける場所がないときの自動パス
- 両者とも置けないときのゲーム終了
- 盤面がすべて埋まったときのゲーム終了
- 終了時の石数表示
- 勝敗表示
